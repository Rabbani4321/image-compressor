HELPFUL DETAILS

Frequently asked questions

Are my details uploaded?

No. QR generation runs in JavaScript on this page. Website links, messages, Wi-Fi names and passwords, email addresses, and phone numbers are not sent to a server or stored by the tool.

What happens when someone scans my QR code?

The scanner interprets the encoded content. A website code opens a link, Wi-Fi codes may offer to join a network, and contact codes can prepare an email or phone action. The scanner may ask the person to confirm.

Can I encode a long message?

QR codes have a finite data capacity. If the content is too long for a valid code, the generator will show an error; shortening the text usually helps.

What is included in a Wi-Fi QR code?

The code contains the network name, security type, and (for secured networks) the password you enter. Anyone who can scan or photograph that code may be able to read those connection details. Share it thoughtfully.

Does this create a dynamic or trackable QR code?

No. This creates a static QR code that directly contains the data you entered. It does not include click tracking or a redirect service.
